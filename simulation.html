DO this using tibbles and map:

sim_results_df = 
  tibble(
    sample_size = rep(30, 1000)
  ) |> 
  mutate(
    est_df = map(sample_size, sim_mean_sd)
    ) |> 
  unnest(est_df)

Look at results:

sim_results_df |> 
  ggplot(aes(x = mu_hat)) +
  geom_density()
